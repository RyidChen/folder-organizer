# Folder Organizer｜下載整理助手

以 C# 與 Windows Forms 製作的 Windows 桌面工具。手動掃描資料夾，預覽並確認後整理檔案，全程在本機執行。

## 直接下載使用

[下載最新 Windows 免安裝版](https://github.com/RyidChen/folder-organizer/releases/latest)

一般使用者在 Release 的 Assets 下載 `FolderOrganizer-v1.0.2-Windows.zip`，按右鍵「全部解壓縮」，再雙擊 `FolderOrganizer.exe` 即可使用，不需要編譯或安裝開發工具。

請放在有寫入權限的位置，並保留程式旁的 `.organizer-state` 設定與復原紀錄。此版本尚未簽署數位簽章，Windows 可能顯示發行者驗證提示。

## 功能

- 來源與整理目的地可自行選擇，目的地預設與來源相同。
- 依檔案類型分類：文件、圖片、影音、壓縮檔、安裝程式及其他。
- 可新增或移除自訂分類，並在預覽中逐檔選擇。
- 顯示掃描進度，支援取消；個別讀取失敗項目會略過並列出原因。
- 比對檔案內容並標示重複項目，不自動刪除。
- 同名檔案加上編號，避免覆蓋。
- 可復原最近一次整理，重新開啟程式後仍有效。
- 自動記住資料夾設定與自訂分類。

## 系統需求與建置

Windows 10／11，需有 .NET Framework 4.5 或更新版本，以及對應的 Framework64 C# 編譯器。本專案不依賴額外 NuGet 套件。

在專案根目錄執行：

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

腳本會編譯程式並執行整合測試。完成後開啟 `dist\FolderOrganizer.exe`。

## 使用方式

1. 選擇來源資料夾與目的地。
2. 按「掃描檔案」，查看分類、重複提示與完整目的地。
3. 勾選要整理的檔案；需要時調整分類。
4. 按「開始整理」，確認後執行。
5. 若需要還原，按「復原上次整理」。

按「管理自訂分類」可新增或移除分類選項。資料夾在確認整理後才建立。移除分類不會刪除磁碟上的資料夾或檔案；預覽中使用該分類的項目會改回「其他」。

## 行為與限制

- 只掃描來源最外層，不遞迴子資料夾；略過隱藏、系統、連結及未完成下載。
- 自訂分類需手動指定，不會自動分析內容或重新命名檔案。
- 取消掃描會清除未完成預覽，不移動檔案。
- 整理或復原前會比對內容；檔案變更、目的地衝突等情況會保留現況並提示。
- 只保留最近一批的復原紀錄，新一批整理會取代舊紀錄。
- 設定與復原紀錄位於程式旁的 `.organizer-state`；請保留此資料夾。復原紀錄不是檔案內容備份。
- 復原不刪除整理時建立的空資料夾。

## 專案結構

- `src/`：桌面介面、整理引擎、設定及資料模型。
- `tests/`：檔案操作、自訂分類、設定與取消掃描等整合測試。
- `build.ps1`：編譯及測試腳本。

測試使用獨立產生的測試資料夾，不操作使用者的下載資料夾。建置結果、本機設定、測試資料與個人文件不納入版本控制。
